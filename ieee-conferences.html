About this list: This is a hand-curated, source-verified directory of one (or two) flagship conferences per major IEEE society/council — not a live feed. IEEE has no public API for conference data, and its conference search site blocks automated scraping, so dates/venues here reflect what was verified on each official site as of July 2026 and can shift. Always confirm on the linked official site before booking travel or submitting a paper.

Try the live IEEE search sources below — the full IEEE conference calendar has thousands of entries beyond this curated set.

Because the official IEEE website blocks direct browser requests, a local python helper script scrape-ieee.py is used. Run this script in your local workspace terminal to refresh the database from official sources:

PowerShell / Command Prompt
# 1. Scrape all 39 IEEE Societies and generate ieee-societies.json
python scrape-ieee.py societies

# 2. Scrape IEEE conferences for a specific query and generate ieee-conferences.json
python scrape-ieee.py conferences --query="robotics"
The scraped data will save to ieee-conferences.json and ieee-societies.json.
